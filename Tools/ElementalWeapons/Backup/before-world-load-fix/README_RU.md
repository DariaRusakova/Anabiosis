# Огнемёт и водяной пистолет — первое лицо

Подготовлены C++-анимация оружия, позы рук Manny, двухручный IK, плавное прицеливание, покачивание при ходьбе/поворотах, отдача и визуальная струя. Исходные модели, UV и текстуры сохранены. Сторонняя анимация полного тела, урон, боезапас и перезарядка не добавлялись.

## Первый запуск в Windows

1. Сохрани проект и закрой Unreal Editor.
2. Запусти `Setup_Elemental_Weapons.bat` из корня `D:\Anabiosis 5.7`.
3. Скрипт найдёт движок проекта **UE 5.7.4**, соберёт `AnabiosisEditor` установленными Visual Studio C++/Windows SDK, импортирует модели и откроет новую карту. Ничего устанавливать самостоятельно он не будет.
4. Нажми Play. Если мышь не захвачена — щёлкни по окну игры.

При необходимости можно указать движок вручную:

```bat
Setup_Elemental_Weapons.bat -EngineRoot "D:\UE_5.7"
```

Каждый запуск создаёт новую папку `/Game/Weapons/Elemental/Build_###`: две модели, PBR-материалы и текстуры, настройки `DA_flamethrower` / `DA_water_pistol`, копии персонажа и GameMode, карту `L_ElementalWeapons_###`. Основой служит последняя успешно построенная карта из `Saved/ThreeIslands/latest_build.json`. Если последний запуск сборщика островов завершился ошибкой, установщик найдёт прежнюю успешную карту по отметке `SAVED` в его логах. `/Game/NewWorld` используется только при отсутствии карт островов; если карты есть, но подтверждение успешной сборки потеряно, скрипт попросит сначала пересобрать острова. Исходные Blueprint, карта и настройки стартовой карты не перезаписываются. При ошибке уже созданная папка остаётся для диагностики; следующий запуск выбирает новый номер.

## Управление

| Действие | Клавиша |
|---|---|
| Ходить / смотреть / прыгать | Текущее управление проекта |
| Огнемёт | `1` |
| Водяной пистолет | `2` |
| Атака | Удерживать ЛКМ |
| Прицеливание | Удерживать ПКМ |

Огнемёт работает непрерывно, пистолет выпускает импульсы примерно раз в 0,24 с. Вход в прицеливание занимает около 0,18 с. Оружие опускается и поднимается при смене. Если менять его с зажатой ЛКМ, для новой атаки отпусти и нажми ЛКМ заново. Ходьба и повороты доступны при атаке и прицеливании.

## Что проверить после перезагрузки

- Оба оружия смотрят вперёд, имеют текстуры и нормальный масштаб; кисти держат рукоятки, пальцы не проходят сквозь корпус.
- Для каждого оружия: атака стоя → WASD во время атаки → ПКМ + атака + движение → повороты вверх/вниз и по сторонам. Нет скачков камеры и застывших рук.
- Отпускание ЛКМ сразу убирает струю. Смена `1/2` во время атаки прекращает старую струю. После смены удерживаемая ЛКМ не запускает новое оружие до повторного нажатия.
- После остановки движения покачивание затухает; после отпускания ПКМ оружие плавно возвращается к бедру. У стены струя не появляется за препятствием.
- Повторный Play и возврат из игры не оставляют лишних обработчиков ввода.

На Linux проверены независимая C++-логика движения и Python-подготовка. В логах Windows от 21 ноября подтверждены успешная сборка первоначального C++-модуля и импорт обеих моделей. Версия установщика **1.0.1** исправляет последующую ошибку доступа к защищённому `Blueprint.Status`: проверка выполняется через native `ElementalWeaponEditorLibrary`, без чтения этого поля из Python. Её пересборка и полный проход установщика требуют следующего запуска в Windows. **Компиляция шейдеров, положение рук в кадре и PIE пока не подтверждены.** Эффекты струй — простая процедурная визуализация для проверки атаки, без урона.

Локальная проверка: 49 C++-проверок состояния, 9 Python-тестов подготовки/установщика, 15 прежних тестов островов прошли. Тесты установщика имитируют границу Unreal для проверки соответствия сжатия/сэмплера и отказа при ошибке Blueprint; они не заменяют реальную компиляцию шейдеров и Blueprint. Обратный импорт обоих FBX в Blender подтвердил сохранение масштаба и положения относительно хвата. Независимое ревью выполнено; найденные проблемы исправлены.

Если хват или положение в кадре требуют подгонки, редактируй созданные DataAsset: `Hip/Aim Location`, `Hip/Aim Rotation`, `Right/Left Hand Offset`, `Right/Left Elbow Offset`, `Muzzle Offset`, `Recoil Scale`, `Sway Scale`, `Aim FOV`. Все расстояния — см; X вперёд, Y вправо, Z вверх. Параметры Mesh Rotation/Scale служат калибровке импорта и уже рассчитываются установщиком. Повторный запуск создаёт новую версию с исходными настройками, поэтому ручную подгонку делай в сохранённой версии.

## Диагностика и исходники

- `Saved/ElementalWeapons/Compile.log` — Windows C++ сборка.
- `Saved/ElementalWeapons/UnrealSetup.log` — импорт и создание карты.
- `Saved/ElementalWeapons/latest_setup.json` — отчёт именно текущего запуска; содержит путь карты, материалы и калибровку.
- `Source/Anabiosis/ElementalWeapons` — состояние, компонент, персонаж и native AnimInstance.
- `Tools/ElementalWeapons/weapons.json` — размеры, точки хвата, текстуры и SHA-256 исходников.
- `Tools/ElementalWeapons/prepare_models.py` — воспроизводимая подготовка FBX в Blender.
- `Tools/ElementalWeapons/Prepared` — производные FBX, извлечённые текстуры и изображения моделей.

## Происхождение ассетов

Все модели и текстуры взяты из уже добавленных в проект файлов. Огнемёт: `Content/Models/flamethrower/source/Flamethrower.zip` и его PNG в `textures`; исходник содержит статические детали, без скелета/анимаций. Производная модель исключает только пилотное пламя `Flamethrower_Flame`, сохраняет корпус, баллон, спуск и детали манометра; длина 90 см.

Пистолет: `Content/Models/sci-fi_pistol.glb`, длина производной модели 35 см. Встроенные метаданные GLB указывают: **Sci-fi Pistol**, **Konstantin Lavrenov / arttopperfx**, [исходная страница](https://sketchfab.com/3d-models/sci-fi-pistol-f117490351bd4bbb944319b7eb09455f), лицензия **CC BY 4.0**. Это сведения из файла, отдельно права не проверялись. Изменения: удаление экспортного преобразования сцены, нормализация осей/масштаба, точка хвата, FBX-экспорт; текстуры извлечены без перекодирования. При распространении сохраняй атрибуцию. Для UE у карты нормалей пистолета инвертируется зелёный канал, ORM подключается как R=AO, G=Roughness, B=Metallic.

Позы и аддитивные анимации рук используются из имеющихся каталогов Manny `Characters/Mannequins/Anims/Rifle` и `Pistol`; передвижение копируется с существующего тела героя. Новых внешних ассетов не скачивалось.
